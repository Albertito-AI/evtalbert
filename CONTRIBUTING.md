# Contributing

This project uses the MIT licence in the root LICENSE file. Use invented
records in tests, demonstrations and issues. Keep actual session records,
credentials and generated files outside the public source tree.

Install the package and run `python -m unittest discover -s tests -v`,
`python scripts/validate_source.py` and `python scripts/readme_demo.py --check`
before proposing a change. Preserve a failing regression for a runtime fix.
Describe the code's observed behaviour separately from any untested scientific
or privacy claim.
