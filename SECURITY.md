# Security policy

EVT-Albert is an early local research prototype. It is not a hosted service, medical device or clinical system.

Never commit credentials, private keys, real session records, health information, identifiable performance data, confidential research material or production databases. Use synthetic data in issues and demonstrations.

Report a suspected vulnerability or data disclosure privately to the repository owner through an established private contact route. Include the affected revision, expected behaviour, observed behaviour and a minimal synthetic reproduction. Do not publish credentials, personal information or an exploit against a live system in a public issue.

There is no public bug bounty or separate security contact at this stage. A report does not create a payment entitlement.
