# Source extraction and regression verification

Recorded 11 November 2026. This is a bounded software-maintenance record, not a
new software release, an independent human review or a scientific study.

## Exact starting point

The source archive was read from repository commit
[`0bcac11bc464552b984dd0aa6ea30a04f2027c91`](https://github.com/Albertito-AI/evtalbert/tree/0bcac11bc464552b984dd0aa6ea30a04f2027c91).
Its filename was `evtalbert_v0_1_0.zip` and its SHA-256 was
`d8560c3592aa1df9779f2168b0a31e510982c681e10e86043468473c41bdf09f`.
The ZIP remains available in that historical commit after removal from the
current source tree. The [member manifest](legacy-source-manifest.json) records
the original size, SHA-256 and disposition of every one of its 22 files.

Extraction selected explicit paths after verifying the archive digest. Ten text
files were extracted: five package modules, the original smoke test, package
metadata, contribution guidance, the code of conduct and ethics notes. Five
generated bytecode files were excluded. Seven archived root documents or
workflows were superseded by the maintained root versions. The archived
proprietary licence and outdated publishing workflow were not activated.

## Reproduced defect and observed verification

On Python 3.12.14 on Linux, the seven-test regression suite was first run against
the extracted, unchanged package modules. Six tests passed, including the original
CLI smoke flow. The Markdown test failed because the entire report was one line
containing literal backslash-n characters. After the one-line correction, all
seven tests passed against the locally installed package. The original smoke
flow starts CLI subprocesses from its temporary directory, outside the checkout.

The checks use invented records only. They cover the CLI initialise/log/report
flow, three-record arithmetic and missing duration, the seven-session rolling
window, Markdown line structure, empty CSV export, identifier hashing without
modifying raw logs, and rejection of a non-integer CLI rating. The hashing test
also confirms that free text is retained; this option is not a general
anonymisation procedure.

For current results, run the documented commands in [README](../README.md) and
inspect the exact commit's
[integrity workflow run](https://github.com/Albertito-AI/evtalbert/actions/workflows/repository-integrity.yml).
The source validator checks the retained provenance structure, source compilation,
installed MIT metadata and tracked-file exclusions. It does not rescan the
historical ZIP on each run. Historical hashes can be independently checked by
reading the ZIP at the pinned starting commit and hashing its member bytes.

These checks do not establish measurement validity, clinical usefulness, a
causal effect on performance, production hardening or real-user acceptance.
There were no real-user records, paid model calls, model-weight changes or
new scientific findings in this maintenance work.
